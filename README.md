# UNNORMAL-ADVENTURE
- HALゲーム学科・三校合同コンテスト作品（一年前期）🏆技術力賞
- 2Dスクロールアクション
- Unity Visual Scripting使用<br>
## 🎮 操作方法
**メニューでの操作**<br>
- ↑ / ↓ ：　選択する<br>
- Space：　エントリーする

**ゲーム内の操作**  
- ← / → ：　歩く  
- Shift 長押し　＋　← / → ：　走る  
- Space：　ジャンプ  
- Z キー　：投げ攻撃  
- X キー　：石の種類を切り替え<br>
